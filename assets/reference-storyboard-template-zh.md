# 中文资产锚定分镜模板（Mode D / F）

用于中文参考图分镜，或用户指定“资产图锚定 → 分段画面 → 输出约束”的提示词格式。保留以下中文字段及顺序，按实际镜头数量展开。用户指定表格或平台原生结构时，以该格式为准；本模板是分镜写作格式，不是通用 API 请求结构。

## 填写规则

1. 先读取用户给出的剧情、时间表及参考图，保留原台词、说话人、动作顺序、时长、镜头数量和已指定首尾帧。只填写本次请求的分镜，不自动扩写全剧或启动生图、视频生成。
2. `<Picture N>` 对应实际上传顺序，全篇固定编号，不改为 `{{Mixed N}}`，不为缺失资产虚构图片编号。一张图可承担多个明确指定的用途；多人图用“从左数第几位”区分角色，多视图是同一个角色。
3. 分开声明角色、场景、道具、首帧和尾帧的用途。角色图只提供形象时不照搬姿势；明确指定的首尾帧则约束相应时刻的构图、姿态、表情和遮挡关系。这一端点要求优先于角色图、场景图的一般使用规则。
4. 有首尾帧或原图保真要求时，加载[参考图保真规则](../references/reference-image-fidelity.md)。描述可见锚点及首尾之间的动作和机位衔接；标签不能代替真实图片输入，文字要求也不等于已验证成片一致。
5. 未提供身高时不编造米数；可说明可见体型或采用已知相对比例。无独立道具图时写明道具来自剧本或画面，保持外形和数量连续。开场无前镜时明确写“本片开场，无前一个分镜”，不补写不存在的前情。
6. 时间段从 0 秒连续覆盖指定总时长，不重叠、不留空。按需求增删分段，不固定为三镜、五镜或 15 秒；同镜中的下摇、跟随不自动算一次切镜。明确每次切入和动作承接，末段写清终止状态及用户要求的停留时长。
7. “画面”写可见动作及起止状态，“禁止”只列本镜实际风险，“约束”写可执行的保持条件；不要机械凑满五条禁令。手部操作应交代左右手、持物与交接；道具破裂、发光、湿润等属性仅在本场需要时填写。
8. 每段安排一个主要动作和一个主导运镜，连续因果动作按先后写明。对白放在“画面”内，标明角色、画外对白或心声；同段不同角色依次说话，不互相抢词。心声不驱动口型，画外对白不让画内其他角色代说。
9. 根据指定时长核对对白与动作是否放得下；保留提问后的停顿、物件落定、断口展示等叙事节点。若约束确实冲突，指出具体冲突并给最小调整方案，不擅自删台词、加速表演或改总时长。
10. 音效写环境底声、动作声和必要的声音衔接；配乐沿用用户要求，未要求时不自动添加。视觉风格来自当前要求、参考图及适用项目约定，不继承示例中的角色、绿光、沼泽、黑暗配色或写实 CG。

## 可填写正文

替换花括号内的说明，删除不适用的资产行和首尾帧规则。分段块按实际数量复制；最终交付只输出填好的正文，不带填写说明和空占位符。

```text

角色 {角色甲} 的参考图是 <Picture {实际编号}>。
角色 {角色乙} 的参考图是 <Picture {实际编号}> {多人图中的人物位置，仅适用时填写}。
场景 {场景名} 的参考图是 <Picture {实际编号}>。
道具 {道具名} 的参考图是 <Picture {实际编号}>。
视频首帧使用 <Picture {实际编号}>。{仅在已指定首帧时保留}
视频尾帧使用 <Picture {实际编号}>。{仅在已指定尾帧时保留}
{无独立参考图的必要道具：说明已知外形、数量和来源，不虚构图片编号。}

出场角色：
{角色甲}，{已知身高或可见体型、识别特征}。
{角色乙}，{已知身高或可见体型、识别特征}。

{地点、时间、天气、光源，以及本场必要的空间结构和氛围。}

---

- 场景参考图：参考场景的位置、大小、形状及结构关系；摄影角度和人物站位按分镜安排，氛围服从当前要求。不出现镜像复制，不把空场景图作为静态插片。
- 道具参考图：参考大小、形状、材质和结构；角度、构图与位置按动作变化，正反面符合客观结构，持握与交接连续。

时间段：{上一段结束时间}-{本段结束时间}秒。{动作标题}。
画面：{说明切入或连续运动，承接上一段的视线、动作与持物状态；对白注明说话人，画外对白或心声另行标明。}
禁止：{本镜具体风险。}
约束：{本镜连续性与关键节点。}
站位与朝向：{人物与物件的相对位置、朝向。}
运镜：{景别、角度、主导运动及终点。}
音效：{本镜声音及与前后镜的衔接。}

时间段：{末段开始时间}-{总时长}秒。{收束动作标题}。

约束：{明确最终人物、持物状态和画面停留时间。}

输出约束：
1. {本次指定的总时长、镜头数量、画幅及首尾帧要求；未指定的不要当作用户硬性要求。}
2. {角色身份、体型、服装及所选人物数量保持连续；不从多视图复制人物。}
3. {必要道具的数量、结构、左右手持握及交接状态保持连续。}
4. {原台词与说话人准确；出镜说话者对应口型，非说话者不代说，心声期间嘴唇闭合。}
5. {场景结构、光源方向及物理接触连续；必要的特殊属性和光照作用在此明确。}
6. {用户指定的声音、配乐与字幕要求，以及本场其他硬性约束。}
```

## 交付前检查

- 资产编号和图片用途一一对应；只有真实提供的图片有 `<Picture N>` 标签，首尾帧不会被角色图的一般规则覆盖。
- 台词、动作顺序、总时长和切点符合当前要求；时间段连续，表演与停顿留有空间。
- 前后镜的视线、画面方向、左右手与道具状态可接；到达尾帧的路径可解释。
- 没有残留占位符、填写说明、示例专属人物或画风，也没有擅自添加的身高、台词或配乐。
- 仅交付分镜时不宣称生成成功。若另需平台原生提示词，按对应适配器转换并保留资产映射、台词和时间线，不将此中文正文冒充已验证的接口结构。
